# แชทบอทน้องบุก — ข้าวบุกสุขใจ 🍚

เว็บแชทบอทขายสินค้า ขับเคลื่อนด้วย OpenAI API (โมเดล `gpt-4o-mini`)
บุคลิก สินค้า ราคา โปรโมชั่น ค่าส่ง FAQ และกลยุทธ์ upsell ทั้งหมดอ่านจาก `config.json` — แก้ไฟล์เดียว บอทอัปเดตทันทีเมื่อรีสตาร์ท

## วิธีติดตั้งและใช้งาน

1. **ติดตั้ง dependencies** (ครั้งแรกครั้งเดียว)
   ```
   npm install
   ```

2. **ตั้งค่า API key** — สร้างไฟล์ชื่อ `.env` ในโฟลเดอร์นี้ แล้วใส่บรรทัดเดียว:
   ```
   OPENAI_API_KEY=sk-xxxxxxxx
   ```
   ขอ API key ได้ที่ https://platform.openai.com/api-keys
   (ต้องการเปลี่ยนโมเดลเป็น `gpt-4o` ใส่เพิ่ม `OPENAI_MODEL=gpt-4o`)

3. **รันเซิร์ฟเวอร์**
   ```
   npm start
   ```
   แล้วเปิดเบราว์เซอร์ที่ http://localhost:3000

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `config.json` | ข้อมูลแบรนด์ สินค้า ราคา FAQ กลยุทธ์ขาย — **แก้ที่นี่** |
| `system-prompt.js` | แปลง config เป็น system prompt ภาษาไทยให้ AI |
| `server.js` | เว็บเซิร์ฟเวอร์ + เรียก OpenAI API |
| `public/index.html` | หน้าเว็บแชท |

## การปรับแต่ง

- **เปลี่ยนราคา/โปรโมชั่น/เพิ่มสินค้า:** แก้ `config.json` แล้วรีสตาร์ทเซิร์ฟเวอร์ (Ctrl+C แล้ว `npm start` ใหม่)
- **ปรับนิสัยการตอบ:** แก้กติกาในส่วน "กลยุทธ์การขาย" หรือ "ขอบเขต" ใน `system-prompt.js`
- **เปลี่ยนสีธีมหน้าเว็บ:** แก้ตัวแปร `--green` / `--cream` ด้านบนของ `public/index.html`

## หมายเหตุ

- ประวัติแชทเก็บในเบราว์เซอร์ของลูกค้าเท่านั้น รีเฟรชหน้า = เริ่มบทสนทนาใหม่
- OpenAI แคช system prompt ที่ซ้ำกันโดยอัตโนมัติ (เมื่อยาวพอ) ช่วยลดค่าใช้จ่ายเมื่อแชทต่อเนื่อง
- อย่า commit ไฟล์ `.env` ขึ้น git (มี `.gitignore` กันไว้แล้ว)
